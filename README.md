# 🪞 Smart Mirror using MagicMirror²

## 📌 Overview
An interactive smart mirror built using Raspberry Pi and MagicMirror² that displays real-time information such as weather, calendar events, and news.

---

## 🚀 Features
- 🕒 Time & Date display
- 🌦️ Weather updates (OpenWeather API)
- 📅 Google Calendar integration
- 📰 News feed
- 🎨 Custom UI using CSS
- ⚡ Auto-start using PM2

---

## 🛠️ Technologies Used
- MagicMirror²
- Node.js
- Raspbian OS
- JavaScript, CSS
- OpenWeather API
- Google Calendar API

---

## 🧰 Hardware Used
- Raspberry Pi 3B+
- Monitor Display
- Acrylic sheet + Two-way mirror film
- Cooling fan & heat sinks
